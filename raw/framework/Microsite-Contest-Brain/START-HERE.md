# The Microsite Contest Brain

Rank Expand Academy. For members only.

## What this is

Everything the Academy learned from the $1,000 Microsite SEO Contest, packed so an AI assistant can read it, understand it and help you make decisions about your own microsites.

It contains every ranking we recorded, a full teardown of the two sites that reached number one, the winner's own account of what he did with his working records, every study and handout we produced, and every daily update.

## Before you use it

This is the third step, not the first.

1. Go through the **Microsite Playbook** modules.
2. Go through the **Microsite Empire** module and get the **Microsite Blueprint**.
3. Then use this.

The Playbook and the Blueprint teach you how to build. This pack is separate and adds to them: it is the evidence of what worked when 61 sites were built and measured. It does not repeat them.

## How to use it with an AI assistant

**The quick way (any chat assistant):**

1. Start a new chat or project.
2. Paste `LLM-INSTRUCTIONS.md` as the instructions.
3. Upload `BRAIN.md` and `DECISIONS.md`.
4. Ask your question. Tell it your service, your town, how old your site is and what is on page one.

**The full way (an assistant with a project or file library, or a coding agent):**

1. Unzip the pack.
2. Add the whole folder to the project, or point the agent at it.
3. Use `LLM-INSTRUCTIONS.md` as the instructions. It tells the assistant which file to open for which question.

**Check it understood.** Ask it three or four questions from `TEST-QUESTIONS.md` and compare the answers. If it gets them wrong, it has not loaded `BRAIN.md`.

## Questions it is good at

- Is this service and town worth building in?
- My site dropped. What do I do?
- How many listings do I need, and which ones?
- Should I start a blog?
- Here is my site. What would the contest say is missing?
- What exactly did the winner do in week one?
- Plan my first 30 days the way the winner ran his.

## What is in the pack

| File or folder | What it is |

| `LLM-INSTRUCTIONS.md` | Instructions for the AI. Paste first. |
| `BRAIN.md` | The core file. Every fact, numbered, and 15 rules. |
| `DECISIONS.md` | 16 common decisions, answered from the evidence. |
| `TEST-QUESTIONS.md` | Questions and answers to check the AI has understood. |
| `MANIFEST.md` | Every file in the pack, its size and when to open it. |
| `knowledge/` | The deep files: results, both number one sites, the winner's account and records, the studies, the corrections. |
| `knowledge/chapters/` | The classroom pages for the contest, as plain text. |
| `winner-site/` | A frozen copy of the winning site, a walk through of it, and a version written for AI assistants. |
| `data/` | Every number as a spreadsheet file: rankings, entries, site comparison, the winner's listings, posts and links. |
| `daily-updates/` | Every update posted during the contest, with a key to the nicknames. |
| `handouts/` | Every PDF handout, and a plain text copy of each. |
| `tools/` | The search link tool we used for every ranking check, and prompts. |

## Three things to know

- **It is frozen.** Rankings stop at the final check on November 17, 2026. One follow up check and one check of the winner's links are kept in a separate file.
- **The winning site is there to study, not to copy.** Use its structure. Write your own words.
- **The radon number one is described, not copied.** It was never entered in the contest, so there is no copy of it here.
