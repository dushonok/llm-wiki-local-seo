**How these rankings are measured**

Nothing paid. I load a Google search URL in a normal Chrome window with English and US set, personalization off, and a location code that puts the searcher in Gettysburg or York. Pages one through four, ten seconds apart, seven loads a day so Google doesn't flag the browser. Before I count anything I check the footer for the town name and "Results are not personalized." Organic links only: no ads, no map pack, no AI box, no forums block. Each domain gets one position, its best URL. Positions 1 to 20 score. I run it this way because every tool I tried, and the built in browser preview, put the new sites ten to fifteen spots higher than Chrome did on the same day.
