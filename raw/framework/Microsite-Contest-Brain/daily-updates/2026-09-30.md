Biggest day of the contest so far.

**Radon**

First contest points in nine days. One site hit 19. It's a 120 page grid built the same way as the mold site in second place. Almost certainly the same contestant, and the only one scoring on both queries.

**What's working**

Breadth is beating depth this week. The site with 60 detailed guides lost five spots. The sites with 100 short location pages gained six and nine.

**Correction**

Last week I said a site lost 15 spots because its server went down. It was never down. A security filter on my network was blocking it. The drop was real, the cause was not.

Tip from that mistake: some home internet filters block brand new domains. If someone says your site won't load, have them try on cellular first.
