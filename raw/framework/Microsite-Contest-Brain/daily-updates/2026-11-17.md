**How these rankings are measured**

The same way since Sept 30. I search in a normal Chrome window with the location set to Gettysburg or York and personalization turned off. Only the regular website links count. Ads, the map box, the AI answer and the forum box are skipped. Each site gets one position, its best page. Positions 1 to 20 score, and only sites on the contest sheet can score.
