# Daily updates

35 updates written during the contest, one file per day, named by date.

Read these as a diary, not as the record.

- Sites are called by nicknames. The key is in `knowledge/14-nicknames-in-the-daily-updates.md`.
- Updates before September 30 used searches that were not location pinned. Their positions flatter contest sites by 10 to 15 places.
- A few updates contain errors that were found later. They are listed in `knowledge/12-corrections-log.md`.
- Positions for any date are in `data/`. If an update and the data disagree, the data is right.
