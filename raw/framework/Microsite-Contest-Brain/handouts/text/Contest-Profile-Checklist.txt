Rules for every profile
Use the same business name, spelled the same way, on every profile.
Use the same phone number and the same town on every profile.
Link every profile to your homepage.
Use the same short description and the same logo everywhere.
Pick one short handle for places that limit length. The winner used GettysburgMold on X, TikTok and
Reddit.
Put one short video on YouTube with the service and town in the title.
Save every profile link in one sheet as you go.
Add those links to your site's code as the sameAs list. The winner also shows five of them in the footer.
Build them in your first week, then leave them alone.
WHAT THIS DOES AND DOES NOT PROVE
Only 3 of the winner's 16 profiles ever ranked on their own, so we cannot say which ones helped the site. What we can say: the one site with this full set finished at number one, and the second place site, which listed no profiles at all, never reached page one. Positions come from searches with the location set to Gettysburg or York and personalization turned off.
