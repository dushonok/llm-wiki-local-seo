# The winning site

- `Winning-Site-LLM-Pack.md`: written for an AI assistant. Specifications, the site code, every page title and six full reference pages. About 30,000 words, so load it only when you need page level detail.
- `Winning-Site-Showcase.html`: a visual walk through for a person. Open it in a browser.
- `Winning-Site-Archive.zip`: a frozen, clickable copy of the site on October 26 (47 pages) and October 27 (119 pages). Forms, phone links and tracking are switched off.

The site was entered in the contest, and the contest rules allow entered sites to be shared with members for study. Use the structure. Do not reuse the text.

These three files were written during the contest and call the site "the leader" in places. Two things in them are out of date: the winner built far more than the 16 profiles named in his code, and the October 27 batch was an accident. See `knowledge/12-corrections-log.md`.
