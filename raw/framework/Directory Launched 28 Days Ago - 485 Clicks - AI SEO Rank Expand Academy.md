Directory Launched 28 Days Ago - 485 Clicks

I started investigating building directory sites a few months back and built this one with the help of Claude Code (meaning it built and connected everything): [http://careertrainingpath.com/](http://careertrainingpath.com/ "http://careertrainingpath.com/")

Happy with the progress so far--a definite win.

It's been live for about a month and currently has 7,114 pages indexed in GSC, with roughly half of the remaining (6,620 pages) not yet indexed. 485 clicks in tht time according to GSC.

If you are thinking of building something similar with CC, start by asking it to create a directory project on your local machine and maintain a project log and knowledge base. Tell it what you want to build and it will start guiding you. When you have an idea or feature you want, tell it and it will build it. Have it backup everything in Github. When you work out a process that you want to reuse without drift, ask it to create a Skill so it works the same every time it uses it.

There is no 'one size fits all' process. basically you are interacting with a very talented IT department that can deliver almost anything you ask for. So keep asking. I use Fable 5.1 which burns through tokens fast but it also builds fast.

Claude Code (CC) can access API data feeds that help populate page content, generate bulk images using Ideogram and perform many other directory centric tasks. You just need to give it permissions. It avoids thin content and avoids boilerplate templating when instructed. It builds for SEO/AEO structure and depending on the data sources it is using, it can automatically add and remove pages as old data is replaced with new. It all comes down to how much back and forth you're willing to invest in designing the project. CC seems able to solve almost any technical issue that comes up.

I first began building in Wordpress using the Directorist plugin on a hosted server but soon discovered it can be wonky. Larger directory sites slow down and run into issues that make it not ideal. So I moved to an Astro based setup hosted on Cloudflare (for free), where it runs quite fast and has had no issues.

CC can do so much more than just design and create the directory. It built a related workflow it called the Link-Flywheel, an automated link building flow. Basically it researched a large set of individuals and organizations that could conceivably have an interest in the subject matter featured in the directory--journalists, trade associations, university librarians and others. Each week it writes and sends individually crafted emails from the domain to 8 - 10 of them, offering some helpful insight. For example it might write to a trade association to point out it was mentioned in a research report featured on the site. It doesn't ask for a link back, but the hope is that over time some will appreciate the mention and link back to the directory. It's a long term strategy but it is essentially free and runs on autopilot. Over time as the sending domain gets some history we'll begin to pick up the pace of sending.

CC also built a backend ad platform (currently just showing a few ads for the newsletter) that could be used to run affiliate product ads, or lead generation ads for featured placements for trade schools and others when traffic supports it. The directory could also integrate an ad platform like Mediavine should traffic levels ever grow high enough. The newsletter is a work in progress, not there yet but all put together by CC.
