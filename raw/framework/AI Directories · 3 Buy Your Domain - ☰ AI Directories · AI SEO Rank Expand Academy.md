## The rules

1. **.com only.**
2. **State plus service, exact match.** `floridapoolbuilders.com`. `poolbuildersflorida.com` works too. Pick one, do not buy both.
3. **The state goes in the name, not a city.** A city name makes it a microsite. The directory ranks for the state term and every city under it.
4. **Never reuse a microsite domain.** A directory and a microsite are different sites with different jobs. Give the directory its own name.
5. **One directory per domain.** A second state is a second domain.
