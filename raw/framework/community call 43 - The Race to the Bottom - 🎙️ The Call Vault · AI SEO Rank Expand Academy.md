#43 - The Race to the Bottom

## Things mentioned

- Claude Code: AI coding agent. William's primary build tool -- he trains it on a process document, then has it invoke his scripts directly.
- DeepSeek: Chinese LLM. 1/10th the cost of Anthropic API, 1M token context window, Anthropic-compatible endpoint. Drop-in backend for Claude Code.
- Replicate: Pay-as-you-go image generation API with access to many models. William uses it alongside Ideogram for site images.
- Ideogram: AI image generation. One of William's top picks for site image production.
- Dream: Image generation tool used by William for site images.
- Mozilla HTTP Observatory ([observatory.mozilla.org](http://observatory.mozilla.org/ "http://observatory.mozilla.org")): Free security header checker. Shlomi got a perfect score. Shawn ran an existing rank-and-rent and got a red F.
- Cloudflare Turnstile: CAPTCHA for form protection. Blocks webhook scraping and spam submissions.
- Manus: AI agent for automated site building. Mark's primary tool at $200/mo.
- GHL (GoHighLevel): Site hosting and CRM in Teja's WaaS stack.
- DataForSEO: Keyword research API. Part of Teja's 4am automation pipeline.
- Gemini: Deep research in Teja's multi-model site pipeline.
- SiteGround Go Geek: Hosting for HTML static microsites. Mark pays $600/yr for the plan.
- AMD Strix Halo: Chipset for high-memory local AI machines (96-128GB+ UMA).
- OpenCode: Uses the right model for each task type to minimize token costs.
- Astro: Static site framework. Shlomi built his first EMD in it with one instruction to Claude.

### Automating the build

William is training Claude on a document that defines his entire site-building process and having Claude invoke his scripts directly. Before Claude Code: 21 hours per site. He's also running DeepSeek as a drop-in backend for non-content tasks at 1/10th the Anthropic cost. For content he still uses Opus. Claude's vision handles image selection automatically, which was previously a fully manual step.

### The subscription model

Teja built a "Netflix for websites" -- $100/mo per site, no upfront cost, no change requests outside the quarterly review. A Claude-managed automation runs at 4am every day: analyzes 1,000+ competitor Facebook ads, returns 50 ranked ad angles, and sends him a morning performance report. He's at 38-40 clients. Target is 50, then hire a VA for change requests only.

### Security as standard

Shlomi launched his first EMD and ran it through Mozilla's HTTP Observatory. Perfect score on the first try. Jesse checked one of his existing rank-and-rents: red F. Claude can fix most of the findings. Best practice: add HTTP Observatory to your build checklist before marking any site done. For forms: add Cloudflare Turnstile and a honeypot, implement rate limiting on submissions, and keep your webhook URL out of public folders.

### Building at scale

Mark started June 4. At time of call: 50 live sites. Stack is Manus at $200/mo plus SiteGround Go Geek at $600/yr. Building four sites a day. Jesse's advice for the next phase: stop doing it the same way every time. Group A gets backlinks, Group B gets nothing, Group C gets different link types. Six months of that and you have real data.

### The bigger picture

William's take: cloud token subsidies are ending. Local AI is coming. Minimum 96GB UMA, ideally 128GB+. AMD Strix Halo is the chipset to watch. Jesse: burn through tokens now while they're cheap. On commoditization: "It is going to be a race to the bottom. And the faster you accept that, the faster you're going to make money." Teja echoed it unprompted on the same call.
