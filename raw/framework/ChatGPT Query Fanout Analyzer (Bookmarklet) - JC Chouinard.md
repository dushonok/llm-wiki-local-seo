# ChatGPT Query Fanout Analyzer (Bookmarklet)

By Jean-Christophe Chouinard, 15 December 2025

This Bookmarklet will help you parse the conversations data from your ChatGPT prompts including the fan-out queries, which URLs rank and what entities are found on the page. It allows you to view the conversation as a Markdown file too.

This was inspired, derived from and adapted from the works of Mike Friedman (TheSEOPUB) and Geeksta.

## Parsing Query Fanouts

Whenever you look into your Chrome DevTools Console you see that ChatGPT gives you a ton of information such as the queries that it sent for each of your prompts via `search_model_queries`.

The author created this bookmarklet to help access that data easily.

## Adding the Bookmarklet

To add a bookmarklet:

1. Right-click on the bookmark bar.
2. Click "Add Page…"
3. Add a name and copy the bookmarklet code (JavaScript, see below) into the URL field of the bookmark.

The script does not track or transmit any user data externally — it runs entirely client-side against ChatGPT's own `/backend-api/conversation/{id}` endpoint using the user's existing session token.

## How it works (read from the script)

1. You must have an open ChatGPT conversation (`chatgpt.com/c/<conversation-id>`) for the bookmarklet to run — it reads the conversation ID from the URL path.
2. It fetches the user's own session token via `/api/auth/session`, then calls ChatGPT's internal `/backend-api/conversation/{id}` endpoint with that token to pull the full raw conversation JSON (the same data ChatGPT's own UI renders from).
3. It walks every message node in that conversation and extracts, per prompt/response pair:
   - **Queries** — from `message.metadata.search_model_queries.queries` (the model's actual fan-out search queries) and `message.metadata.search_queries`.
   - **Citations/Links** — from `message.metadata.search_result_groups`, `message.metadata.content_references` (grouped webpages, sidebar citations, footnote sources, business/map results), each capturing URL, title, snippet, attribution/domain, and publish date where available.
   - **Entities** — parsed out of special encoded markers in the response text.
   - **Model info** — which model slug(s) answered (e.g., gpt-4o, gpt-4o-search).
   - **Image groups / attachments** — if present.
4. It opens a new tab and renders all of this as a dashboard: one collapsible section per prompt, with toggleable columns (Queries, Entities, Footnotes, Links, Supporting, Image Groups, Model Info).
5. You can **Export Selected** columns to CSV (one CSV per selected column type, e.g. a `Queries_Report.csv` with every fan-out query per prompt, or a citations CSV with URL/domain/title/snippet per citation), or **View Markdown** to get the full conversation as a Markdown transcript.

## Practical implication for citation research

This tool turns a single ChatGPT conversation into a structured export of:
- every fan-out sub-query ChatGPT actually ran to answer the prompt, and
- every URL/domain ChatGPT cited while answering — with type (grouped citation, sidebar citation, footnote source, business map result, etc.), domain, title, and snippet.

This is the practical mechanism behind "pull fan-out queries and cited sources from ChatGPT" — it requires no API cost (unlike DataForSEO), just an open ChatGPT session and one click, but it only captures one conversation at a time (not aggregated/automated across many queries).
