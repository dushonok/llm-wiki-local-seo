# Montreal Maps cold outreach (field playbook)

Compounding notes from **Google Maps prospecting** in Greater Montreal (roofing focus, Nov 2026). Use with [[sales-and-lead-generation.md]] Approach #1 (human touch) and Approach #4 (Maps prospecting). Not a script library for every niche — a **filter + pitch type + follow-up** guide so the next session does not re-derive the same lessons.

**Geo rule:** Target **Montreal metro + Vaudreuil–Soulanges / South Shore / Laval** local trades. **Deprioritize** national contractors with toll-free routing and central marketing (see [[#National / multi-branch — when to skip the phone hook]]).

---

## Prospect filter (30-second triage)

| Signal | Action |
|--------|--------|
| Site **down** or GBP website link **404/500** | **Pitch:** stop the bleed (restore or one-page on same domain); urgency high |
| **Name** or **one primary phone** differs GBP vs site (single location) | **Pitch:** alignment sprint; high fit for owner-operator |
| **Two+ GBPs** + site shows **one** main office | **Pitch:** each fiche ↔ labeled bureau on site; name Valleyfield (or exact Maps address) if that's the broken fiche |
| **Two phones**, site lists **multiple cities/offices** | **Medium:** pitch **routing clarity** (footer: bureau + number), not "you made a typo" |
| Homepage **1-877** + `/locations/` multi-province | **Low / skip** for owner cold call — national intake is intentional |
| **Receptionist** on main line | Never say **marketing digital / SEO / agence**; lead with **fiche Google + street** |

## Pitch types (what to sell first)

### 1. Offline or broken website (Maps link dead)

**Example:** [[#Prospect log — Roofing Renovations Dompro]]

- Hook: "Your Google listing still sends people to a site that doesn't load."
- Offer tier: triage/fix → rebuild on **same domain** → retainer after live
- Do **not** open with full SEO audit

### 2. Brand / entity split (legal name vs trade name)

**Example:** [[#Prospect log — Construction KRP Inc. / Roof Star]]

- Hook: GBP **Construction KRP Inc.** vs site **Roof Star**; **438** on Maps vs **514 / 1-833** on site
- Offer: pick customer-facing name + one primary line; footer shows legal + trade; schema `legalName`
- Soften: clarity and hesitation before call — avoid hard "#1 ranking" claims on first touch

### 3. Multi-GBP vs single-site story

**Example:** [[#Prospect log — Couvreur de l'Ouest Inc.]]

- Hook: **fiche Valleyfield** (562 C Rue Gaétan, 438) does not match what **toiturevaudreuil.ca** shows (Vaudreuil, 450) — **ça coûte des clients** when callers bounce
- Offer: footer or Contact with **each bureau + phone**; optional second GBP hygiene; align each listing to the right bureau on the site (see [[local-seo-checklist.md]] NAP — website categories/services match GBP)
- User copy pattern: phone example + **et d'autres écarts**; CTA **au moment qui vous convient**

### 4. National / multi-branch — when to skip the phone hook

**Example:** [[#Prospect log — Atlas-Apex (Laval listing)]]

- **Atlas-Apex:** Laval GBP **514** vs site **1-877-221-7663** — branch vs national line by design
- Pitch only if targeting **QC marketing / branch manager** (listing junk services, French local path) — not the standard alignment sprint to the owner on a cold call

## Receptionist and identity (hard rule)

**2026-11-24 — Couvreur de l'Ouest:** Receptionist asked who was calling; user said **digital marketing** → hang-up.

| Avoid on switchboard | Use instead (FR) |
|----------------------|------------------|
| Marketing digital, SEO, agence | « **[Prénom]** — j'appelle pour la **fiche Google** (Rue Gaétan / Valleyfield) et **toiturevaudreuil.ca**, ce n'est pas de la pub » |
| Long pitch before routing | Ask: **qui gère Google ou le site** |

**After hang-up:** one **SMS or email** (no vendor label) + one **gatekeeper call** in 7–10 days → then **park** and prospect elsewhere.

---

## French call skeleton (alignment / multi-GBP)

Use for trades when user wants **coûte des clients** + flexible CTA:

> Bonjour, est-ce que je parle au responsable de **[nom]**? Vous avez **[une / deux] fiche(s) Google**. Celle à **[adresse Maps exacte]** — **[téléphone]** — ne concorde pas avec **[domaine]**, **et d'autres écarts**. **Ça vous coûte des clients.** On aligne chaque fiche avec le bon bureau sur le site. **Est-ce qu'on pourrait en parler plus au moment qui vous convient?**

**Dompro variant (site down):** lead with Maps **Website** button → server error, not NAP lecture.

**KRP variant:** two names (KRP vs Roof Star) + phones; same CTA.

---

## Follow-up cadence (voicemail / gatekeeper)

1. **Text or email** within 1–2 hours: one factual hook + question **who owns Google/site**
2. **Second touch** in **7–10 days** (call or email); **3 touches / 2 weeks** max per [[sales-and-lead-generation.md]]
3. **No response** → next prospect; keep dossier below at **parked**

## Multi-location website rule (foot in door)

When pitching regional roofers with **legitimate multiple offices**:

- **Footer / Contact:** each bureau with **address + phone** (e.g. Valleyfield 438, Vaudreuil 450)
- **Each GBP** primary phone should match **that** bureau on the site
- Do not collapse to one number on the homepage without labeling **which bureau**
