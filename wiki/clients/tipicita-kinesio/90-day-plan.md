# 90-Day Plan — tipicita-kinesio.com Le Bouscat relocation SEO

Execution tracker for [recommendations.md](recommendations.md). Start date =
today, **2026-10-08**. Owner column: `Em` = Emmanuelle (content/GBP access
only she has), `Dev` = whoever can edit Wix code/custom code injection
(Velo/Editor), `SEO` = whoever is running this plan. Re-check this page and
tick off items as they're done rather than creating a duplicate tracker.

**Why this phasing:** schema/citation fixes (P0) are pure technical corrections
with no content risk — do them first and in parallel with nothing else blocking.
Visible on-page copy (P1) comes next since it requires no new writing, just
edits to existing copy. Content build-out and the coach-de-vie keyword push
(P2) come last because they take longest to pay off and should ride on top of a
clean technical foundation, not substitute for one.
